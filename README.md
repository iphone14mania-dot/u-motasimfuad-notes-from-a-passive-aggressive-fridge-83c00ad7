One line written as a note from a passive-aggressive fridge: six days of faithful cold storage, repaid with a 2 a.m. stare — and even the yogurt has lost respect. The program deterministically writes exactly one line to `entry.txt`. No network, no randomness, no dependencies.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
